# 术语表 按问题查概念

[返回入口](../README.md) · [基础](01_foundations.md) · [点云与 Mesh](02_pointcloud_mesh.md) · [MANO](03_mano_hand.md) · [3DGS](04_nerf_3dgs.md) · [4DGS](05_4dgs.md)

**使用方式**：先看“它回答什么”，再去对应章节做练习。下列解释采用本教程约定，不能替代某个数据集或软件自己的字段定义。资料核验日期：**2026-10-03**。

## 1 我手里是什么数据

| 术语 | 中文与直观含义 | 易混点 |
|---|---|---|
| Point cloud | 点云，一组带坐标的样本 | 没有默认面连接，也不自动定义实体内部 |
| Vertex | 顶点，Mesh中的位置记录 | 表面顶点不是骨架关节 |
| Face / Triangle | 面/三角形，用顶点索引定义连接 | 三点存在不代表软件自动知道它们应该连成面 |
| Mesh | 网格，顶点加面连接等属性 | 可以开口；不一定是可用实体或精确CAD |
| Topology | 拓扑，哪些点和面如何相连 | 坐标相同不代表连接关系相同 |
| Normal | 法线，局部表面的朝向 | 点云法线往往由邻域估计；方向符号可能不一致 |
| UV / Texture | 表面到二维图像的映射/纹理 | 纹理细节可以很高，几何仍然很粗 |
| Voxel | 体素，空间中的小网格单元 | 体素可以存占据、距离、颜色等不同数值 |
| Occupancy | 占据值，表示某位置在物体内部/被占据的情况 | 概率占据与二值占据不同；不直接给到表面的距离 |
| SDF | 有符号距离场，本教程外正内负 | 符号约定因实现而异；开口网格未必有可靠内外定义 |
| TSDF | 截断有符号距离场，主要保存表面附近距离 | 适合多帧深度融合，不会自动修正错误相机位姿 |
| PLY / OBJ / STL | 常见三维文件容器/格式 | 仅凭后缀不能推断单位、面、材质和自定义属性 |
| NPZ | 多个NumPy数组的归档 | 不是“MANO专属格式”；需核对keys、shape和语义 |

展开：[三维表示与文件格式](01_foundations.md)。官方参考：[Open3D 几何教程](https://www.open3d.org/docs/0.19.0/tutorial/geometry/index.html)、[NumPy savez](https://numpy.org/doc/stable/reference/generated/numpy.savez.html)。

## 2 位置 时间和相机

| 术语 | 它回答什么 | 必须附带的约定 |
|---|---|---|
| Coordinate frame | 坐标系，位置相对哪个原点/坐标轴描述？ | 世界、相机、物体、机器人基座等 |
| Pose | 位姿，一个刚体的位置和方向 | 表达在哪个参考系、变换方向 |
| Extrinsics | 外参，坐标系之间怎么变换？ | world-to-camera 或 camera-to-world |
| Intrinsics | 内参，相机内部如何将射线映射到像素？ | 分辨率、焦距、主点及具体相机模型 |
| Distortion | 畸变，真实镜头如何偏离理想投影？ | 模型类型、系数顺序、是否已去畸变 |
| Depth | 深度，本教程针孔公式指相机轴向Z坐标 | 不要直接等同于光心到点的射线距离 |
| Range | 射线距离，光心/测量原点到点有多远？ | 测距原点、方向及单位 |
| RGB-D | 彩色图加深度图 | 两者可能不是同一像素网格；需空间与时间配准 |
| Back-projection | 反投影，由像素和深度还原三维点 | 深度语义、K、畸变、单位 |
| Reprojection | 重投影，把估计的三维点投回图像 | 小像素误差不等于小毫米误差 |
| Axis-angle | 轴角，方向是转轴，模长是角度 | 常用弧度，不是欧拉角三分量 |
| Quaternion | 四元数，一种旋转表示 | `wxyz/xyzw`、约定及归一化 |
| Timestamp | 时间戳，数据在哪一时刻采集？ | 单位、时钟源、同步误差，非仅帧号 |
| Scale ambiguity | 尺度歧义，投影不能单独确定整体物理大小 | 普通单目SfM需额外尺度参照 |

展开：[坐标与相机](01_foundations.md)。官方参考：[OpenCV 标定](https://docs.opencv.org/4.13.0/d9/d0c/group__calib3d.html)、[COLMAP 位姿约定](https://colmap.github.io/format.html)。

## 3 我在执行什么步骤

| 术语 | 输入到输出 | 不能顺便保证的事 |
|---|---|---|
| Calibration | 标定，观测已知模式等信息 → 相机/传感器参数 | 一次标定不覆盖之后改变的镜头和采集配置 |
| SfM | 重叠图像 → 相机与稀疏三维结构 | 未必有绝对尺度、稠密表面或完整物体 |
| MVS | 多视角图像及相机 → 较密集的深度/表面观测 | 透明、反光和无纹理区域仍会困难 |
| Registration | 配准，多份几何 → 共同坐标下的对齐 | 对齐残差低不保证对应关系正确 |
| ICP | 迭代最近点，一种局部精配准方法 | 一般需要合理初值，不保证全局正确 |
| RANSAC | 对含离群值的数据反复采样拟合候选 | 仍依赖模型、阈值和足够正确对应 |
| Downsampling | 降采样，降低点数/密度 | 若尺度太大会丢掉薄壁和细节 |
| Surface reconstruction | 表面重建，点/法线/体数据 → 连续表面近似 | 补出的区域不等于实际观测到 |
| Poisson reconstruction | 利用有方向法线估计平滑表面 | 容易在无观测处形成推测表面 |
| Watertight | 水密，表面满足封闭性相关条件 | 水密不等于外形准确，也不等于力学模型可靠 |
| Manifold | 流形，局部连接像正常连续表面 | 非流形边/点会给某些算法带来问题 |
| Self-intersection | 自交，表面片穿过表面片 | 好看的渲染可能隐藏自交 |
| Rendering | 渲染，从模型和相机计算图像 | 图像逼真不能替代几何检验 |
| Fitting | 拟合，调整模型参数解释当前观测 | 拟合好训练观测不保证唯一真实状态 |
| Training | 训练，调整可学习参数以降低目标损失 | 3DGS训练常指单场景优化，与大规模通用模型训练含义不同 |

展开：[点云处理工作流](02_pointcloud_mesh.md)。官方参考：[COLMAP 教程](https://colmap.github.io/tutorial.html)、[Open3D ICP](https://www.open3d.org/docs/0.19.0/tutorial/pipelines/icp_registration.html)、[表面重建](https://www.open3d.org/docs/0.19.0/tutorial/geometry/surface_reconstruction.html)。

## 4 MANO 手部和动态表示

| 术语 | 本教程中的含义 | 应问的下一句 |
|---|---|---|
| MANO | 参数化人手形状和姿态模型 | 是前向生成，还是另一个网络正在估计它的参数？ |
| Beta / Shape parameters | 形状参数，控制统计手型变化 | 模型版本与形状基数目是什么？ |
| Theta / Pose parameters | 姿态参数，控制骨架/表面变形 | PCA系数、完整轴角还是旋转矩阵？ |
| PCA | 主成分分析，用较少系数组合原始高维变化 | 维数、基和均值是否匹配？ |
| LBS | 线性混合蒙皮，按骨骼影响权重变形表面 | 所用骨架、权重和根节点是什么？ |
| Joint | 骨架关节节点 | 是16个MANO节点中的哪个？ |
| Landmark | 被指定的几何/语义点，如指尖 | 是骨架点、表面顶点，还是回归点？ |
| 21 hand landmarks | 常见的16骨架点加5指尖协议 | 顺序是什么？是否已经追加过指尖？ |
| Retargeting | 动作重定向，把源动作映射到另一副运动学结构 | 保留指尖目标、动作外形还是任务接触？ |
| NeRF | 神经辐射场，用连续场描述空间中的密度与视角相关外观 | 哪种实现、哪些相机和训练观测？ |
| 3DGS | 用有位置、形状、透明度和外观参数的3D高斯表达场景 | 文件字段和渲染器协议是什么？ |
| Splatting | 将空间基元的投影贡献混合到图像中 | 不是把一个中心点当一个普通像素画出来 |
| 4D | 三维空间加时间这一常见语境 | 表示的是随时间变化的几何、外观还是场？ |
| 4DGS | 时变高斯场景方法的统称/相关方法名 | 是3D高斯加变形场，还是显式时空高斯？ |
| Deformation field | 变形场，位置/时间 → 变形 | 有无对应、刚性或时间一致性约束？ |
| Canonical space | 规范空间，用共同参考状态组织变形 | 映射方向和参考时刻是什么？ |

展开：[MANO](03_mano_hand.md)、[NeRF 与 3DGS](04_nerf_3dgs.md)、[4DGS](05_4dgs.md)。具体方法、论文和实现区别见对应章节，不以“4D”一个词替代算法说明。[MANO 官方项目](https://mano.is.tue.mpg.de/)

## 5 判断结果时的语言

| 术语 | 读报告时要检查 |
|---|---|
| Ground truth / 真值 | 是直接测量、人工标注、优化拟合还是仿真生成？误差与适用范围是什么？ |
| Confidence / 置信度 | 是概率、模型分数、可见性、点支持密度还是人为阈值？不同量不能互换 |
| Accuracy / 准确性 | 与独立参考相差多少？参考本身有多少误差？ |
| Repeatability / 重复性 | 相同条件重复测量是否一致？重复性好不排除系统偏差 |
| Resolution / 分辨率 | 能区分多细的结构？更多顶点不等于传感器分辨率提高 |
| RMSE | 均方根误差，对大残差较敏感；必须注明单位、方向、样本和对齐方式 |
| Held-out view | 未参与优化的独立视角；用于检查能否解释新观测 |
| Ablation / 消融 | 改变一个组件，检查它是否真正带来效果 |
| Contact candidate | 几何上可能接触的位置；受尺度、噪声、阈值影响 |
| Contact force / 接触力 | 需要额外传感、材料/动力学或统计假设；几何不能唯一确定 |
| Reproducibility / 可复现性 | 是否能依据数据版本、环境、参数和步骤重做并核对结果？ |

### 四句自检

1. “有一个模型”还不够：是哪种表示，单位和坐标是什么？
2. “已经重建成功”还不够：独立检查过尺度、几何和失败区域吗？
3. “误差很小”还不够：以什么对齐方式、什么单位、对什么参考算的？
4. “公开可下载”还不够：代码、数据、模型和输出分别受什么许可约束？
